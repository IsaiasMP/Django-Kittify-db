Proyecto en Django para gestionar artistas, álbumes y canciones con sus letras.  
Incluye administración desde el panel de Django y funcionalidades para visualizar y editar letras de canciones.

---

## 🚀 Características
- Administración de **álbumes** y **canciones** desde el Django Admin.
- Vista inline de canciones dentro de cada álbum.
- Hipervínculo en el nombre de la canción para acceder a su detalle.
- Campo editable para agregar o modificar letras.
- Soporte para imágenes de portada de álbumes.
